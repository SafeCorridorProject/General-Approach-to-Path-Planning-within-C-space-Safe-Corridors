In this folder there is the source code for recreating the simulations made for comparison with OMPL library.
The main classes and related methods for creating the robot models are defined, which are: ChJoint, ChPlanModel, ChPlanner (these classes are the same ones used for our algorithm) . In addition, a class is provided to be able to define 6-axis robots: ChRobot, ChRobot_6dof, ChRobot_6dof_CAD. The actual implementation of the OMPL library is created in the files "ChPlannerOMPL.cpp", "ChPlannerOMPL.h", which define the methods for using the planners provided by OMPL. The various CAD models are present in the appropriate folders: "CAD_model" for the first simulation environment (blocks), "shelves" for the second simulation environment, and finally "laser" for the third simulation environment. In addition, the CAD export folders are present, thus with the corresponding .cpp and .h files. CAD_export2 for the first simulation (blocks), CAD_export3 for the second simulation (shelves), and CAD_export_coll for the third simulation (laser) (In this folder (OMPLimplementation), there is only "CAD_export_coll", which is the one used for the third environment (laser). For the other two environments, the folders are the same as those found in the repository. (In any case, "CAD_export_coll" has the same contents as the "CAD_export_new" folder found in the repository.)). It is possible to run the simulations via the "main" file. Installation of the “Project Chrono” software (https://projectchrono.org/) and the various dependencies (https://api.projectchrono.org/install_guides.html) are required for proper operation. Installation of the OMPL library and its dependencies are required.
